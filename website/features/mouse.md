# Mouse — Aerox 9 Wireless

Control the SteelSeries Aerox 9 Wireless over USB (wired or 2.4 GHz dongle). The
tab shows a "not connected" state when the mouse is absent.

![Mouse](/mouse.png)

## What you can control

- **DPI presets** — up to five steps with the active one highlighted.
- **Polling rate** — 125 / 250 / 500 / 1000 Hz.
- **Lighting** — per-zone RGB (top / middle / bottom), a rainbow mode, and
  reactive click flashes.
- **Power saving** — sleep and dim timeouts.
- **Battery** — live level, with a charging indicator.

::: info
The battery read path is verified on real hardware. When both the cable and the
dongle are connected Inari prefers the wired node. See the
[Protocols reference](/reference/protocols) for the HID details and the DPI code
table.
:::
